# VISIBI WordPress theme

Upload post featured images at **1600×900 pixels**. The Insights listing uses the hard-cropped `visibi-card` image size (16:9) for its featured and grid cards.

Service-page case and article covers are editorial sector imagery, not client storefront screenshots. The abstract marks in empty certification and testimonial-logo slots are decorative, not official badges or customer logos. Replace them with approved assets through **VISIBI Images** in WordPress admin when available.
